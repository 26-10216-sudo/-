# Solar Odyssey - 3D 태양계 탐험 앱 (Three.js)

Three.js 기반의 고품질 3D 인터랙티브 태양계 탐험 및 시네마틱 우주선 투어 웹 애플리케이션입니다.

## ✨ 주요 기능
1. **태양계 3D 시뮬레이션**:
   - 태양과 8대 행성 (수성, 금성, 지구, 화성, 목성, 토성, 천왕성, 해왕성) 및 지구의 달 구현.
   - 실제 비율 감각을 고려한 공전 궤도 및 자전 모션.
   - 토성과 천왕성의 아름다운 고리(Ring) 3D 표현.
   - 각 천체별 동적 절차적 텍스처(목성의 대적점 및 가스 띠, 지구 대륙/구름, 태양 플레어 등).

2. **🚀 우주선 투어 모드 (Cinematic Spaceship Tour)**:
   - 우측 상단의 **[우주선 투어 시작]** 버튼을 누르면 태양부터 해왕성까지 우주선 시점으로 자동 순항 비행.
   - 조종석 HUD 조준선 오버레이 및 상단 투어 상태 배너 (이전/다음 건너뛰기 지원).

3. **인터랙티브 컨트롤 & 탐색**:
   - 3D 뷰에서 행성을 마우스로 직접 클릭하거나 하단 네비게이션 바를 눌러 특정 행성으로 부드러운 줌인/초점 이동.
   - 마우스 드래그(회전), 휠 스크롤(줌), 우클릭 드래그(팬) 자유 시점 지원.
   - 공전 속도 조절 슬라이더 (일시 정지부터 최대 3배속까지).
   - 행성별 주요 제원(지름, 태양과의 거리, 공전/자전 주기, 상세 설명)을 담은 글래스모피즘 정보 카드.

## 🚀 실행 방법
별도의 설치나 빌드 과정 없이 웹 브라우저에서 바로 열 수 있습니다:

- `index.html` 파일을 더블 클릭하여 Chrome, Edge 등의 브라우저에서 실행하거나,
- 로컬 웹 서버(`npx serve` 또는 VS Code Live Server 등)를 통해 열어보실 수 있습니다.
